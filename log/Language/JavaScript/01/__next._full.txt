<h2 id="heading-02-01-00">클라이언트와 서버</h2>
<h3 id="heading-02-01-01">서버 컴퓨터 (server computer)</h3>
<ul>
<li>인터넷에 직접 연결된 컴퓨터</li>
<li>사이트에서 사용하는 텍스트와 이미지, 동영상, 게시판 정보 등 사이트와 관련된 모든 정보가 저장돼있음</li>
</ul>
<h3 id="heading-02-01-02">클라이언트 컴퓨터 (client computer)</h3>
<p>사용자가 인터넷 정보를 볼 때 사용하는 PC나 노트북, 태블릿, 스마트폰</p>
<h2 id="heading-02-02-00">프런트엔드 개발과 자바스크립트</h2>
<h3 id="heading-02-02-01">프런트엔드(front-end)</h3>
<ul>
<li>앞(front)에 있어서 사용자에게 보이는 부분을 가리킴</li>
<li>웹 사이트나 애플리케이션에서 내용을 작성하고 화면을 디자인하는 것부터 사용자의 동작에 반응해서 결과를 만드는 것들이 모두 프런트엔드 개발의 역할</li>
</ul>
<h3 id="heading-02-02-02">프런트엔드 개발에서 많이 사용하는 프레임워크와 라이브러리</h3>

<li>React</li>
<li>Vue.js</li>
<li>Angular</li>
</ul>
<h2 id="heading-02-03-00">백엔드 개발과 자바스크립트</h2>
<h3 id="heading-02-03-01">백엔드(back-end)</h3>
<ul>
<li>뒤(back)에 있어서 사용자에게 보이지 않는 부분을 말함</li>
<li>클라이언트 쪽에서 어떤 요청을 하면 서버에서는 요청을 처리하기 위한 프로그램을 실행하는데, 이때 서버에서 실행할 프로그램을 만드는 것이 백엔드 개발</li>
</ul>
