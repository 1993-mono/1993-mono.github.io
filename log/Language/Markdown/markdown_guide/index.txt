<h1 id="heading-06-00-00">Emphasis</h1>
<p>There are several ways to emphasize text.</p>
<p>Bold text can use the <code>&#x3C;strong></code> tag, italic text can use the <code>&#x3C;em></code> tag, and strikethrough can use the <code>&#x3C;del></code> or <code>&#x3C;s></code> tag.</p>
<p>Use <code>&#x3C;strong></code> for bold emphasis, <code>&#x3C;em></code> for italic emphasis, <code>&#x3C;del></code> to indicate deleted content, and <code>&#x3C;s></code> when you only want the strikethrough style.</p>
<p>Symbols like <code>**</code>, <code>*</code>, and <code>~~</code> may not render in every environment, so using tags such as <code>&#x3C;strong></code>, <code>&#x3C;em></code>, <code>&#x3C;del></code>, and <code>&#x3C;s></code> is recommended.</p>
<pre><code class="language-markdown">&#x3C;strong>bold text&#x3C;/strong> or **bold text** or __bold text__  
&#x3C;em>italic&#x3C;/em> or *italic* or _italic_  
&#x3C;strong>&#x3C;em>bold and italic&#x3C;/em>&#x3C;/strong> or ***bold and italic*** or ___bold and italic___  
&#x3C;del>strikethrough&#x3C;/del> or &#x3C;s>strikethrough&#x3C;/s> or ~~strikethrough~~
</code></pre>
<h3 id="heading-06-00-01">Usage</h3>
<p><strong>bold text</strong> or <strong>bold text</strong> or <strong>bold text</strong><br>
<em>italic</em> or <em>italic</em> or <em>italic</em><br>
<strong><em>bold and italic</em></strong> or <em><strong>bold and italic</strong></em> or <em><strong>bold and italic</strong></em><br>

<h1 id="heading-10-00-00">Tables</h1>
<p>Tables are written using pipes (<code>|</code>) and hyphens (<code>-</code>).<br>
A minimum of three hyphens is enough.<br>
Using four, like indentation, makes them easier to remember.</p>
<pre><code class="language-markdown">| Header 1 | Header 2 | Header 3 |
|----|----|----|
| Cell 1 | Cell 2 | Cell 3 |
| Cell 4 | Cell 5 | Cell 6 |
</code></pre>

</code></pre>

<h2 id="heading-10-02-00">Limitations of Standard Markdown Tables</h2>
<p>Standard Markdown table syntax (pipes and hyphens) cannot express the following two features:</p>
<ul>
<li><strong>Cell merging (colspan / rowspan)</strong><br>
There is no syntax for merging cells horizontally or vertically. When needed, use <code>colspan</code> and <code>rowspan</code> on an HTML <code>&#x3C;table></code>.</li>
<li><strong>th inside tbody (row headers)</strong><br>
Only the first row is recognized as a header. There is no syntax for separating <code>&#x3C;thead></code>/<code>&#x3C;tbody></code> or adding a row header (<code>&#x3C;th scope="row"></code>) to each data row. In these cases, you must write the HTML table directly.</li>
</ul>
